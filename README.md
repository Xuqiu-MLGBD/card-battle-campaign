# 卡牌对战 · 关卡挑战版

一套**自己写架构、自己写规则、自己写界面**的单人卡牌闯关网页游戏（纯前端、无构建、无联机），
并附带一张可直接装进 **MMD 沙盒新聊天页**的同层卡。

在线跑法：`cd 关卡挑战版 && python 工具/启动.py`（或 `python -m http.server` 后开 `index.html`），
不需要 `npm install`，没有任何后端。

---

## 一分钟了解

| 入口 | 干什么 |
|---|---|
| **卡牌图鉴** | 列出全部卡（费用 / 身材 / 词条 / 说明），数值与规则**同源** |
| **开始游戏** | **挑战关**五关（部署格数逐关 +1，第一关双方各 1 格 → 第五关 5 格，按进度解锁）<br>**自由关**三档（双方各 1 / 3 / 5 格） |
| **更多内容** | 占位一键 |

直达某一局：`?level=1`…`?level=5`、`?free=1|3|5`。

**玩法**：法力每回合 +1；**打人不挨反击**（除非目标带「反击」词条，且**打完还活着**才还手）；
出手要付 `攻耗` 体力（付到 0 就死）；本回合没出手的随从，回合结束回 `恢复` 点血。

## 架构（真正花力气的地方）

零件不稀奇，**接线方式**才是重点。照「唯一写入路径 + 事件驱动 + 权威/展示分离」接线：

```
输入（拖拽 / 点选 / Bot 决策）
      ↓ 一律变成同一条「意图」，只有一个出口
意图层      → 参数校验 → 非法输入落进检错层（不静默丢弃）
      ↓
规则核心    引擎.js（纯逻辑、可回放）+ 卡库.js（卡与效果是同源数据表）
      ↓ 拒绝一律带码（27 条）→ 文案.js 翻成中文（玩家看到的话只有这一处）
提交点      状态.js：采一份权威状态 → 求差 → revision + 1 → 记事件
      ↓                     ↑ 形状与引擎一致（单位映射 + 场上放 id），变更可回放
展示        演出.js（锁 + 队列 + 跳过）→ 界面.js 渲染；展示可滞后，跳过动画 = 强制追平权威
      ↕
检错        检错.js：层 + 码 + 上下文 → 聚合器 → 诊断报告（四道闸：构建 / 装载 / 运行 / 回归）
```

**已经立成规矩的几条**（每条都是踩过坑换来的，代码注释里写了"为什么"）：

1. 一个量只许有一个写入点（发牌、法力上限、玩家看到的话）。
2. 拒绝必须结构化（引擎码表 ↔ 文案表，缺一条机器就报红）。
3. 输入先变成意图：拖拽与点选发同一条出牌意图，玩家与 Bot 发同一条攻击意图。
4. 权威状态 ≠ 展示状态；`revision` 每次提交 +1，"跳过动画"= 追平到最新版本。
5. 要分发的树**整树复制**，只允许"排除"、不允许"搬家"（搬一次就断引用，事故记录见 `说明/16`）。
6. 检查必须**既有牙（该红会红）又不无理取闹（不该红不红）**：判据用"加载事实"而不是"计算结果"，
   每条断言写清它在什么状态下才成立。
7. 沙盒里**别信 `document.getElementById`**（平台会改写查找）：一律走根部作用域 + 骨架 id 自愈，见 `说明/17`。

## 怎么验（都不需要浏览器）

```bash
cd 关卡挑战版
node 工具/跑全部测试.mjs        # 五套一起跑，汇总并给红套的失败行
node 工具/引用体检.js .         # 静态引用闸门：页面引用的本地文件是否都在被引用的位置
python 工具/建沙盒卡.py --check  # 沙盒卡是否与当前源码同一次构建（构建戳一致才 ✓）
```

浏览器里再敲一句（页面自检 49 条，含"本地资源齐备""样式真的落到元素上""关键落点没被图层盖住"
"局开了牌桌就看得见""偷改 DOM 会被对账抓到"）：

```js
HS_INTERACT.check()        // → { 通过, 失败, 总数, 就绪 }
HS_CHECK.报告()             // → 全链路检错的诊断报告（层 + 码 + 上下文）
```

## 进 MMD（沙盒同层卡）

`输出/关卡挑战版-沙盒卡.json` 可直接导入：**新建卡 → 首次保存前把「新版聊天页」选成"使用新版" →
创卡页「导入正则」选那份 JSON**（漏第二步会白装，细节见 `输出/交付说明-沙盒卡.md`）。
人设要手工粘贴（`输出/人设-卡牌对战.txt`）。

**改完源码必须重打包**：卡里的 JS 是构建期内联的，不重打包就还是旧代码（用
`python 工具/建沙盒卡.py` 重建、`--check` 校一致性）。卡目前 28 条规则，**每条 ≤ 20000 字符**
（编辑器上限），过大的模块由打包器自动切片运输。
